# Alibaba Lab

Локальный стенд на ASP.NET Core 10. Нужны .NET SDK 10, FFmpeg в PATH и доступ к CDN для Bootstrap и jQuery.

```powershell
dotnet run --project AlibabaLab --no-launch-profile
```

- http://127.0.0.1:5192/ — одна аудиозапись или MP4, первая аудиодорожка, шкала времени и осциллограмма, масштаб, прослушивание, отметки конца реплики и начала ответа. Разность отметок выводится в миллисекундах, включая отрицательные значения при перекрытии. Лимиты загрузки — 250 МиБ и 30 минут.
- http://127.0.0.1:5192/chat.html — каталог `GET /models`, выбор модели, чат с историей и потоковый `POST /chat/completions`. TTFB измеряет время от старта браузерного запроса до первого блока тела ответа. «Первый текст» измеряет время до первого непустого фрагмента ответа. «Всего» измеряет время до завершающего события SSE. Эти метрики включают локальный прокси и сетевой путь. Сравнение запускает по три коротких запроса на модель и ранжирует модели по медиане времени до первого текста.

## Подключение Alibaba

Приложение читает `.env` из корня решения или по пути из `ALIBABA_ENV_FILE`. Для локальной установки также предусмотрен путь `I:\Repos\alibaba\.env`. Поддерживаются имена ключа `DASHSCOPE_API_KEY`, `API-KEY` и `API_KEY`. Ключ используется на сервере. Скопируйте региональный Base URL из Model Studio в `DASHSCOPE_BASE_URL` (переменная окружения или запись в `.env`). По умолчанию используется сингапурский DashScope `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`.

Для первого теста выберите `qwen3.8-flash` или `qwen-flash` и отключите thinking. Модель в каталоге может требовать отдельной активации. Отправьте короткое сообщение для проверки генерации и квоты. У некоторых моделей параметр `enable_thinking` не поддерживается. Снимите флажок «Отключить thinking», чтобы опустить этот параметр.
